# BioSecure

A Vite + React project with a modern dashboard-style UI featuring interactive charts, farm health monitoring, disease tracking, and admin views.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/KizeBright/BioSecure.git
cd BioSecure
```

### 2. Install dependencies

```bash
npm install
```

This will install all required packages including:

- **React** & **React DOM** — UI framework
- **Vite** — build tool and dev server
- **Tailwind CSS** — utility-first CSS framework
- **Radix UI** — accessible component primitives
- **Lucide React** — icon library
- **Recharts** — charting library
- **React Router** — client-side routing
- **React Hook Form** — form management
- **MUI (Material UI)** — component library
- **Framer Motion** — animations
- **Sonner** — toast notifications
- **Expo** — mobile support (optional)

### 3. Run the development server

```bash
npx vite
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production

```bash
npx vite build
```
